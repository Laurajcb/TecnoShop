# TecnoShop

Catálogo virtual de productos tecnológicos (celulares, computadores, audífonos y parlantes), desarrollado por el subgrupo 13 del curso **Desarrollo de Software en Equipo** (Politécnico Grancolombiano) con la metodología **TSP**.

## Estructura del repositorio

| Carpeta | Qué contiene |
| --- | --- |
| `frontend/` | Aplicación en Angular (interfaz del catálogo) |
| `backend/` | API en Flask (Python) con base de datos SQLite3 |
| `docs/` | Diseño, contrato de la API, plan de pruebas y guías del equipo |
